Known Vulnerabilities

Human-readable explanations for the version notices emitted by the Security Audit job's plugin version check.

About this page #

The Security Audit job downloads security-plugin-versions.json and surfaces any notice associated with the running Rock version. This page documents the reasoning behind each notice, including affected versions, risk, and recommended action. Entries should remain factual and tied to a notice in the published versions file.

Notice schema #

The notices object in security-plugin-versions.json maps a Rock version to a short message. The Security Audit job displays the message verbatim; this page is the long-form companion.

{
  "notices": {
    "17.1.0": "If you're using Microsoft Entra or Auth0 in Rock Mobile...",
    "17.6.0": "Rock 17.6 improves security and includes...",
    "18.1.0": "The Self-Service Kiosk (Preview) site and related blocks..."
  }
}

Current entries #

Status

No published entries. The Security Audit job will continue to surface notices from security-plugin-versions.json while detailed entries are being prepared.

Entry template #

Use the structure below when adding a new entry. Each entry should correspond to exactly one notice in security-plugin-versions.json.

Vulnerability or notice title

Affected Rock versions
For example, 17.5.0 through 17.5.3.
Plugin notice
The exact message published in security-plugin-versions.json.
Risk
The practical security or operational exposure the notice is intended to communicate.
Recommended action
The Rock upgrade, plugin upgrade, configuration change, or manual review that resolves the notice.
