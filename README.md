#### Overview
This plugin provides a set of tools to help Rock administrators monitor and maintain the security of their Rock instances. It provides a daily email summary of potential security issues with your Rock configuration and a set of tools to analyze your IIS logs from within Rock. The Lava Approvals tool can use AI to scan for Lava and SQL vulnerabilities across common areas like blocks, workflows, and shortcodes.

IIS alerts support both scheduled historical log queries and real-time request rules. Real-time rules can evaluate multiple AND/OR conditions before authentication, after authentication, or at the end of a request. For Rock API routes, post-authentication rules run after Rock has processed Forms, API-key, JWT, or OIDC credentials. These rules can require or exclude membership in a selected Rock security role without adding a database query to each request: a compact username-to-person map is refreshed in the background and membership uses Rock's existing role cache. End-of-request rules can inspect response status, duration, content type, and headers. Current-request blocking is available before or after authentication; end-of-request rules can block the client IP on subsequent requests. Historical log queries remain the supported way to alert on completed response sizes.

Additional documentation can be found at https://security.redeemertech.com
